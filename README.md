# TaskFlow — Project & Task Management

Full-stack project management app with kanban board.

## Features
- Create/manage projects
- Tasks with priorities, due dates & status
- Kanban board with drag-and-drop
- Analytics dashboard

## Stack
React 19 · TypeScript · Tailwind CSS · Vite · React Query · Shadcn/UI

## Run
```bash
npm install && npm run dev
```
Requires [portfolio-api-server](https://github.com/WebGhost01/portfolio-api-server).
